# 전체 수동 테스트 체크리스트

배포한 뒤 **실제 폰(아이폰 1대 + 안드로이드 1대, 또는 가족 폰 2대)**으로 한 번 쭉 해 본다. 자동 테스트(`e2e/run.mjs`, `e2e/offline.mjs`)가 같은 흐름을 가짜 AI로 확인하지만, 실제 AI·실제 카메라·실제 폰 동작은 여기서만 확인된다.
표시: ☐ 할 것 · 괄호 안은 기대 결과.

## 0. 준비

- ☐ Worker `https://…workers.dev/health` → `"ai":{"provider":"claude",…}`, `"guard":{"allowList":N,"perMinute":true,"daily":true}`
- ☐ 앱 주소를 폰에서 열면 회백색 바탕에 "우리집 요리"와 "Google로 시작하기"가 보인다
- ☐ Anthropic 콘솔에 **월 지출 한도**가 걸려 있다

## 1. 설치·로그인·가족

- ☐ 아이폰: 사파리 → 공유 → 홈 화면에 추가 → 솔잎색 아이콘으로 열기 → Google로 시작하기 → 로그인 유지(앱을 완전히 닫았다 열어도). 로그인 아래 "아이폰 홈 화면 앱에서는 로그인이 안 될 수 있어요"가 보이면 README "아이폰 로그인"대로 authDomain을 맞춘다
- ☐ 안드로이드: 크롬 → 앱 설치 → 아이콘으로 열기 → 로그인
- ☐ 첫 사람: "새 가족 만들기" → 가족 이름 → 레시피 탭이 열린다
- ☐ 오른쪽 위 "가족" → 우리 가족 화면: 초대 코드 "복사"(아이폰은 "보내기"도)
- ☐ 둘째 사람: "초대 코드로 참여" → 같은 레시피·냉장고가 보인다
- ☐ 우리 가족 화면에서 기본 인분·맵기·아이와 함께 먹어요를 바꾸면 바로 "저장했어요". 싫어하는 재료·늘 있는 양념은 눌러서 고친다
- ☐ 오늘 남은 AI 사용 횟수가 보인다(Worker에 하루 한도 KV를 켰을 때)
- ☐ 허용 목록에 없는 구글 계정으로 AI 기능을 쓰면 막힌다

## 2. 레시피 만들기·가져오기

- ☐ 레시피 탭 → "레시피 추가" → 음식 이름으로 만들기 → "알리오올리오", 3인분, 추가 요청 "덜 맵게" → 레시피 만들기 → 20~60초 뒤 "레시피 확인·수정"
- ☐ "인기 레시피 찾아서 참고"를 켜고 만들면 상세 아래 "참고한 곳"에 웹 출처가 남는다(시간이 조금 더 걸리고 AI 사용 2회)
- ☐ 확인·수정에서 재료 이름·양·단위를 고치고 "재료 추가"·"팁 추가" → 저장
- ☐ 링크·사진에서 가져오기 → 유튜브 링크(설명란에 레시피) → 가져오기 → "유튜브 설명란에서 찾았어요", 저장 후 "원본 보기"
- ☐ 블로그 링크(네이버 블로그 포함) → 본문에서 정리. 못 읽으면 "캡션·사진으로" 안내
- ☐ 인스타 링크 → 캡션·사진 탭으로 바뀐다 → 캡션 붙여넣기 + 스크린샷 → 정리하기
- ☐ 레시피가 없는 영상 → "‘요리 이름’ AI로 만들기"
- ☐ 요리책 사진만 올려도 정리된다
- ☐ 안드로이드: 유튜브 앱에서 공유 → "우리집 요리" → 바로 가져오기. 아이폰: README의 단축어 "요리앱에 저장"으로 같은 동작
- ☐ 만들다 닫으면 "저장 안 한 초안"으로 남고 "이어서"/"버리기"가 된다

## 3. 레시피 상세·요리 모드

- ☐ 인분 −/+ → 양이 환산되고 "기준 n인분에서 자동 환산했어요". "약간"은 그대로
- ☐ 재료 옆 표시: 있음(체크) · 양 확인(노랑) · n 부족(노랑) · 없음 ›(누르면 냉장고 품목과 연결하거나 대체 찾기)
- ☐ "냉장고에 n/m개 있어요" → "장보기에 담기"(선택 재료는 기본으로 빠짐, 같은 재료는 양만 더함)
- ☐ AI 줄: "레시피 바꾸기"(예: 덜 맵게) → 바뀐 레시피가 확인·수정 화면으로 열리고 원래 레시피는 그대로
- ☐ "셰프에게 묻기" → 질문 칩이나 직접 질문 → 답 + 이어 묻기 칩. "새 대화"로 지운다
- ☐ 없는 재료가 있으면 "대체 재료 찾기" → 냉장고에 있는 것 위주로 대신할 재료
- ☐ 싫어하는 재료가 들어 있으면 배너 + "빼고 바꾸기"
- ☐ 즐겨찾기 별, 더보기 → 수정하기 / 식단에 넣기 / 폴더 옮기기 / 삭제
- ☐ "요리 시작" → 어두운 화면, 큰 글씨, 그 단계 재료만 보인다
- ☐ "n분 타이머 시작" → 큰 타이머, "+1분", 다른 단계로 가도 위 줄에 남는다. 끝나면 소리·진동
- ☐ 좌우로 밀어 단계 이동. 읽어주기 켜면 단계마다 읽는다. 안드로이드 크롬에서 마이크로 "다음/이전/타이머"
- ☐ 요리 중 화면이 꺼지지 않는다
- ☐ "AI 셰프에게 묻기" → 어두운 대화 시트. 시트에서 옆으로 밀어도 단계가 바뀌지 않는다
- ☐ 마무리 → "재료 정리하고 끝내기" → 재료 정리 시트(쓴 양이 채워져 있음, 단위 다르면 직접) → "냉장고에서 n개 빼기" 또는 "냉장고는 그대로 두기" → 상세 맨 아래 "요리 기록 1회"
- ☐ 안드로이드 뒤로가기·아이폰 스와이프백이 시트·화면을 닫고 앱은 닫히지 않는다

## 4. 냉장고·영수증

- ☐ 냉장고 탭: 문이 열리고 칸(냉동·윗칸·가운데·아랫칸·야채칸·문 칸·실온장)에 품목이 보인다
- ☐ "채우기" → 영수증·주문내역 → 영수증 찍기(긴 영수증은 나눠 최대 4장) → 분석하기 → "n개를 찾았어요"
- ☐ 확인 화면: 행을 눌러 이름·양·보관·기한 수정, "식품이 아닌 항목"은 접혀 있고 기본으로 빠짐 → "냉장고에 넣기 (n개)" → 떨어지는 애니메이션
- ☐ 장보기에 있던 품목은 영수증으로 넣으면 장보기에서 빠진다("장보기 n개 완료")
- ☐ "채우기" → 식재료 사진 → 장본 것·냉장고 안을 찍기 → 식재료 찾기 → 이미 있는 품목은 기본으로 빠져 있다
- ☐ 분석 중에 닫으면 결과가 보관돼 다시 열 때 "이어서"
- ☐ "채우기" → 직접 추가 → "대파 2개, +3일" → 야채칸에 D-3 빨간 배지
- ☐ 품목 누르기 → 수정 / "다 먹었어요" → 토스트의 "장보기에 담기"
- ☐ "문 닫기" → 문에 임박 재료 메모. 검색하면 안 맞는 품목이 흐려진다. "목록" 보기도 된다
- ☐ 다른 가족 폰에 실시간으로 보인다

## 5. 장보기

- ☐ "우유 2", "삼겹살 600g"처럼 빠르게 추가 → 분류별 카드
- ☐ 둥근 체크 → "담은 것"으로 내려가고 아래에 "담은 n개 냉장고에 넣기"가 뜬다 → 보관 위치·기한 확인 → "n개 넣기" → 냉장고 탭에서 떨어진다
- ☐ X로 지우면 토스트 "되돌리기"
- ☐ 위쪽 "영수증"으로 바로 영수증 채우기

## 6. 뭐 먹지

- ☐ "빨리 먹어야 해요"에 사흘 안 기한 재료(추정은 "~D-1"). 누르면 꼭 쓸 재료로 골라진다
- ☐ "조건" → 분위기(15분 안에 등)·빼고 싶은 재료·인분 → "이 조건으로 추천받기" → 10~20초 뒤 추천 카드
- ☐ 카드: 쓰는 냉장고 재료, 살 것 → "살 것 담기"(→ 담았어요), "레시피 만들기"(→ 바로 생성), "다른 메뉴"
- ☐ "내 레시피로 바로": 지금 냉장고로 만들 수 있는 저장 레시피(AI 안 씀)
- ☐ 레시피 탭 머리 "임박 n"을 누르면 이 탭으로 온다

## 7. 이번 주 식단

- ☐ 뭐 먹지 → "이번 주 식단 짜기" → 날짜 옆 "추가" → 끼니(아침·점심·저녁)·인분 → 레시피 누르기
- ☐ 레시피 상세 → 더보기 → 식단에 넣기 → 오늘~6일 뒤 중 하루·끼니·인분
- ☐ "부족한 재료 n개 장보기에 담기" → 오늘부터 남은 식단을 합쳐 냉장고와 맞춘 목록(선택 재료·늘 있는 양념 제외, 이미 장보기에 있으면 기본으로 빠짐) → "n개 담기"
- ☐ 지난주·다음 주로 넘겨 보기, "이번 주로"
- ☐ 뭐 먹지 탭 "오늘 식단"에 오늘 정한 요리가 보이고 누르면 레시피가 열린다
- ☐ 다른 가족 폰에도 같은 식단이 보인다

## 8. 오프라인·다크 모드

- ☐ 비행기 모드 → 앱을 완전히 닫았다 열어도 레시피·냉장고·장보기·식단이 보인다(한 번이라도 온라인에서 열어 본 것)
- ☐ 탭 머리 왼쪽 "오프라인" 표시. 누르면 무엇이 되는지 안내
- ☐ 끊긴 채로 냉장고에 재료 추가·장보기 체크 → 바로 반영. 비행기 모드를 끄면 다른 폰에도 나타난다
- ☐ 끊긴 채로 AI 기능을 누르면 기다리지 않고 "인터넷이 끊겨 있어요"
- ☐ 폰을 다크 모드로 바꾸면 앱도 어두워진다(냉장고 그림은 흰 가전처럼 조금 어둡게)

## 9. 비용·안전 (가끔 확인)

- ☐ Anthropic 콘솔 사용량이 예상 범위인지(레시피 1건 약 100원 안팎)
- ☐ 하루 한도를 넘기면 "오늘 쓸 수 있는 AI 사용량(n회)을 다 썼어요" 안내, 한국 자정에 풀린다
- ☐ 다른 가족 데이터는 보이지 않는다(초대 코드 없이 참여 불가)
