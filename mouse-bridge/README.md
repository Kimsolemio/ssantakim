# MouseBridge

마우스 하나로 Windows PC 두 대를 오가는 프로그램입니다. 마우스를 화면 끝으로 가져가면 커서가 다른 PC로 넘어가고, 키보드 입력과 클립보드, 파일도 함께 따라갑니다.

- 마우스/키보드 넘기기
- 클립보드 공유 (텍스트, 이미지)
- 파일 복사·붙여넣기 (한쪽에서 Ctrl+C, 다른 쪽에서 Ctrl+V)
- 파일 드래그 앤 드롭 (파일을 끌고 화면 끝을 넘기기)

## 1. 두 PC 연결하기

PC끼리는 일반 USB 케이블(양쪽이 같은 A-to-A 케이블, 충전용 C-to-A 케이블)로 직접 통신할 수 없습니다. 꽂아도 동작하지 않고 포트가 손상될 수 있으니 사용하지 마세요.

MouseBridge는 **양쪽 PC에 네트워크 어댑터로 인식되는 연결**이면 무엇이든 사용합니다. 아래 중 하나를 준비하세요.

| 연결 방법 | 포트 조합 | 비고 |
|---|---|---|
| USB 3.0 기가비트 랜 어댑터 2개 + 랜선 1개 | A↔A, A↔C, C↔C 전부 | 가장 확실합니다. 데스크탑에는 A형, 노트북에는 C형 어댑터를 쓰면 됩니다. PC에 랜 포트가 이미 있으면 그쪽은 어댑터가 필요 없습니다. |
| USB 3.0 데이터 링크 케이블 | A↔A, 젠더로 A↔C | 가운데 칩이 달린 PC 간 전용 케이블입니다. "네트워크 모드"를 지원해 양쪽에 네트워크 어댑터로 잡히는 제품이어야 합니다. |
| USB-C 케이블 직결 | 양쪽 모두 Thunderbolt 또는 USB4 포트일 때 | 케이블 하나로 네트워크가 잡힙니다. |
| 같은 공유기 (유선 LAN 또는 Wi-Fi) | — | 케이블 없이 먼저 시험해 볼 때 쓸 수 있습니다. |

연결 경로가 여러 개면 유선이면서 가장 빠른 경로를 자동으로 고릅니다.

전용 전송 프로그램으로만 동작하는 구형 "Easy Transfer" 케이블은 지원하지 않습니다.

## 2. 설치와 실행

1. `MouseBridge.exe`를 두 PC에 각각 복사합니다. 설치 과정은 없고, Windows 10/11이면 바로 실행됩니다.
2. 두 PC에서 실행합니다. 작업 표시줄 오른쪽 아래 트레이에 파란 마우스 아이콘이 생기고, 처음 실행하면 설정 창이 열립니다.
3. **연결 코드**를 맞춥니다. 한쪽 PC에 표시된 코드를 다른 PC의 설정 창에 그대로 입력하고 `저장`을 누릅니다.
4. **상대 PC 위치**를 고릅니다. 한쪽에서만 정하면 다른 쪽은 자동으로 반대쪽으로 맞춰집니다.
5. Windows 방화벽 창이 뜨면 **개인 네트워크와 공용 네트워크를 모두 체크**하고 허용합니다. USB 직결은 Windows가 "공용 네트워크"로 분류하기 때문입니다. 창을 놓쳤다면 설정 창의 `방화벽 허용 추가` 버튼을 누르세요 (관리자 확인 창이 한 번 뜹니다). 두 PC 모두에서 해야 합니다.

상태가 `연결됨`으로 바뀌면 준비가 끝난 것입니다. 케이블을 꽂은 직후에는 Windows가 주소를 잡는 데 1분 정도 걸릴 수 있습니다.

`상대 PC를 찾는 중…`에서 넘어가지 않으면 설정 창의 **상대 PC 주소**에 상대 PC의 IP를 직접 입력하세요. IP는 상대 PC의 명령 프롬프트에서 `ipconfig`로 확인합니다.

## 3. 사용법

| 하고 싶은 일 | 방법 |
|---|---|
| 다른 PC 조작 | 마우스를 상대 PC 쪽 화면 끝으로 밀기 |
| 내 PC로 돌아오기 | 반대쪽 화면 끝으로 밀기 |
| 즉시 내 PC로 복귀 | `Ctrl + Alt + Home` |
| 텍스트·이미지 옮기기 | 한쪽에서 복사, 다른 쪽에서 붙여넣기 |
| 파일 옮기기 (복사·붙여넣기) | 파일을 `Ctrl+C` 하고 다른 PC에서 `Ctrl+V` |
| 파일 옮기기 (드래그) | 파일을 끌고 화면 끝을 넘긴 뒤 원하는 폴더에 놓기 |

파일을 드래그하면 커서 옆에 `파일 받는 중… %`가 표시됩니다. 수신이 끝나면 일반 드래그처럼 원하는 곳에 놓을 수 있습니다. 수신이 끝나기 전에 버튼을 놓으면 `다운로드\MouseBridge` 폴더에 저장됩니다.

케이블이 빠지거나 연결이 끊기면 마우스는 자동으로 내 PC로 돌아옵니다.

## 4. 알아 둘 점

- UAC 확인 창, 잠금 화면, 관리자 권한으로 실행된 프로그램은 Windows 보안 정책 때문에 상대 PC에서 조작할 수 없습니다. 관리자 프로그램을 조작해야 하면 MouseBridge를 "관리자 권한으로 실행"하세요.
- 다른 PC를 조작하는 동안 내 PC의 커서는 화면 가운데에 숨겨집니다.
- 파일을 붙여넣을 때 큰 파일은 전송이 끝날 때까지 탐색기가 잠시 기다립니다. 4GB 이하는 커서가 넘어오는 순간부터 미리 받아 둡니다.
- 받은 파일은 임시 폴더를 거치며, 임시 파일은 프로그램을 다시 시작할 때 정리됩니다.
- PC 2대만 연결합니다.
- 통신은 연결 코드로 암호화됩니다. 코드를 모르는 PC는 연결할 수 없습니다.

## 5. 처음 사용할 때 점검표

이 프로그램의 통신과 Windows 연동 부분은 자동 테스트로 확인하지만, 실제 PC 두 대에서 마우스가 넘어가는 동작은 직접 확인이 필요합니다.

- [ ] 두 PC 모두 상태가 `연결됨`으로 표시된다
- [ ] 마우스가 양쪽 방향으로 넘어간다
- [ ] 상대 PC에서 클릭, 휠, 한/영 전환을 포함한 키 입력이 된다
- [ ] `Ctrl+Alt+Home`으로 즉시 돌아온다
- [ ] 텍스트와 이미지(캡처)를 복사해 상대 PC에 붙여넣을 수 있다
- [ ] 파일을 복사해 상대 PC 폴더에 붙여넣을 수 있다
- [ ] 파일을 끌어서 상대 PC 폴더에 놓을 수 있다
- [ ] 케이블을 뽑으면 마우스가 내 PC로 돌아오고, 다시 꽂으면 자동으로 연결된다

문제가 생기면 트레이 아이콘 메뉴의 `로그 폴더 열기`에서 `log.txt`를 확인하세요.

## 6. 직접 빌드하기

.NET SDK 8 이상이 필요합니다. 결과물은 .NET Framework 4.8용 exe 하나입니다.

```
dotnet test  tests/MouseBridge.Core.Tests
dotnet build src/MouseBridge.App -c Release
```

`src/MouseBridge.App/bin/Release/net48/MouseBridge.exe`가 만들어집니다. GitHub Actions의 `MouseBridge` 워크플로도 같은 exe를 빌드해 아티팩트로 올립니다.

`MouseBridge.exe --selftest 결과.txt`를 실행하면 그 PC에서 입력 후킹, 입력 재생, 클립보드가 동작하는지 점검해 결과를 파일로 남깁니다. 점검 중 커서가 잠깐 움직입니다.

## 구조

```
src/MouseBridge.Core/   OS와 무관한 로직 (암호화 통신, PC 탐색, 파일 전송, 화면 경계 계산)
src/MouseBridge.App/    Windows 앱 (입력 후킹과 재생, 클립보드, 드래그, 트레이)
tests/                  Core 단위 테스트와 루프백 통합 테스트
```
